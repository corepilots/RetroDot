Drittanbieter-Komponenten / Third-party components

Retro Dot enthält keine Schriften, Bibliotheken, Bilder oder Programmcode von Dritten, die eine eigene Lizenz mit Hinweispflicht erfordern. Die Pixelziffern und Pixelbuchstaben sind eigene Bitmap-Grafiken (5×7- und 3×5-Raster), die aus einer eigenen Rasterdefinition erzeugt werden. Die App ist ein reines Ressourcenpaket im Watch Face Format und enthält keinen Programmcode.

Retro Dot contains no third-party fonts, libraries, images or executable code that require a licence notice. The pixel digits and letters are original bitmap graphics (5×7 and 3×5 grids) generated from our own grid definitions. The app is a resource-only package in Watch Face Format and contains no executable code.
